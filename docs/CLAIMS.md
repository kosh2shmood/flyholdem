# Claims boundary

Required full-data wording: “A simulated network using the wiring of one reconstructed male fruit-fly central nervous system controls an engineered heads-up no-limit Hold'em interface.”

Current V0 statement: A synthetic fixture neural circuit controls a real play-chip PokerKit interface. It is a visual prototype, not a full-connectome result.

Nonzero spikes, weight movement and wins do not establish learning. A learning statement requires the preregistered conditioning/transfer and poker endpoints, controls, retention and parameter-erasure evidence. Keep fixture/circuit/full, bio-plastic/distilled-connectome, teacher-connected/disconnected, and development/confirmatory labels separate. No living fly, consciousness, faithful whole-brain emulation, or proven learner without the required evidence.
